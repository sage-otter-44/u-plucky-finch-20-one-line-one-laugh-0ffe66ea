A make.fun bounty entry: one funny line of text, at most 200 characters, judged head-to-head by an AI judge.

The entry program (`main.ts`, Node 22) writes the line to `/output/entry.txt`:

> The self-checkout flagged an unexpected item in the bagging area. It was my dignity. It has been sitting there since 2019.

Run it with `node main.ts`.
